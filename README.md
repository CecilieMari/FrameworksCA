# 🛍️ React eCommerce Store — JavaScript Frameworks CA

This project is an eCommerce web application built with **React** as part of the *JavaScript Frameworks Course Assignment (CA)* at Noroff.  
It was my first project using a modern frontend framework and focused on learning **component-based development**, **state management**, and **routing** in React.

---

## ✨ Features

- **Main Page:**  
  Displays a list of products retrieved dynamically from an API.

- **Single Product Page:**  
  Shows detailed information about a selected product, including images, descriptions, and pricing.

- **Shopping Cart:**  
  Allows users to add, remove, and review products before checkout.

- **Checkout Page:**  
  Users can finalize their purchase and confirm order details.

- **Contact Page:**  
  Includes a form where users can send inquiries or feedback.

- **Responsive Design:**  
  Optimized for both desktop and mobile viewing.

---

## 🧠 Learning Outcome

This assignment introduced me to working with **React** for the first time.  
I learned how to structure a frontend project into reusable components, manage application state, and handle navigation with React Router.  
The project also helped me improve my understanding of how dynamic data and interactivity can enhance user experience.
